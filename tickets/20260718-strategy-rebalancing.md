# 전략 버킷 기반 리밸런싱

## 목표

전체 계좌를 하나의 포트폴리오로 보고, 기존 종목 태그를 전략 버킷에 연결해 목표 비중과 현재 비중을 비교한다. 앱은 매매를 자동 실행하지 않고 월 적립금 배분과 리밸런싱 필요 여부를 제안한다.

## 범위

- 전역 메뉴에 `전략` 페이지를 추가한다.
- 활성 전략은 사용자당 하나만 지원한다.
- 전략 버킷은 이름, 목표 비중, 정렬 순서를 가진다.
- 하나의 기존 태그는 활성 전략의 하나의 버킷에만 연결할 수 있다.
- 전략의 목표 비중 합계는 100%여야 한다.
- 대상은 전체 계좌이며, 버킷별 평가는 연결 태그가 달린 보유 종목의 평가 금액 합계로 계산한다.
- 월 적립금은 부족한 버킷에 비례 배분한다.
- 현재 비중이 목표에서 설정된 허용 이탈 폭을 넘으면 리밸런싱 필요 상태와 매도·매수 제안을 표시한다.
- 친구 포트폴리오에서는 `자산 / 전략 / 기록`을 읽기 전용으로 보여 주고, `설정`만 숨긴다.

## 데이터 모델

- `strategies`: 사용자별 활성 전략, 월 적립금, 점검 주기, 허용 이탈 폭.
- `strategy_buckets`: 전략 버킷의 이름, 목표 비중, 정렬 순서.
- `strategy_bucket_tags`: 기존 `tags`와 전략 버킷의 연결.

## 수용 기준

- 전략이 없을 때 생성 화면이 표시된다.
- 버킷과 태그 연결을 저장하면 목표 비중 합계 및 태그 중복이 검증된다.
- 전략 페이지는 목표·현재 비중, 목표 금액, 현재 금액, 차이, 이번 달 적립금 배분을 표시한다.
- 허용 이탈 폭을 넘은 경우에만 매도 포함 리밸런싱 제안이 나타난다.
- 친구는 전략과 활동 기록을 읽을 수 있지만 전략을 수정할 수 없다.
