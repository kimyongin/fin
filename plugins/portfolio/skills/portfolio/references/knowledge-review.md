# 투자 지식 검토

## 현재 사실과 관련 지식

배분·전략 판단에는 `get_daily_context` 또는 필요한 현재 상태 조회로 원칙·보유·목표 배분·관련 할 일을 확인한다. 기준 시각과 시세/환율 누락을 확인한다. 최근 활동 목록만으로 필요한 지식을 다 읽었다고 보지 않는다.

질문에서 주제·종목·시간 범위를 추론한다. 태그가 도움이 되면 `list_activity_tags`로 실제 이름을 확인하고 `search_activities`로 관련 기록을 찾는다. 같은 대화에서 확인한 태그는 재사용한다. 중요한 근거는 `get_activity`로 원문을 읽는다. 찾는 방법을 사용자가 지정할 때까지 기다리지 않는다.

| 자료 | 검색과 해석 |
| --- | --- |
| 이론 | 관련 주제·적용 조건·한계를 찾는다. 최근 기간을 일괄 적용하지 않는다. 후보가 적으면 목록을 넓게 확인하되 모든 본문을 매번 읽지 않는다. |
| 뉴스 | 사건 발생일·발표일·기록일을 구별한다. 최신 변화와 이전 배경·정정을 함께 보며 저장된 뉴스만으로 현재 시장을 확정하지 않는다. |
| 결정 | 최신 유효한 선택과 이전 이유·대체 관계를 찾는다. 오래된 장기 보유 이유도 유효할 수 있다. AI 제안·사용자 채택·계획·실제 변경을 구분한다. |

이 구분은 해석·태그 제안 기준이다. 별도 내부 종류·필수 태그·개수 상한이 있다고 가정하지 않는다. 사용자 원칙은 채택한 기준이며 이론은 검토 자료다. 최신 뉴스가 원칙이나 장기 판단보다 자동으로 우선하지 않는다.

## 태그와 검색 실패

- 분류와 주제를 조합할 수 있다. 예를 들어 기존 `투자 이론`과 `투자 심리` 태그를 함께 찾는다. 예시 이름을 새 태그 생성 지시로 취급하지 않는다. 같은 뜻의 기존 태그를 재사용하며 날짜·각 결론마다 태그를 늘리지 않는다.
- 시장 종목은 실제 지원하는 티커 참조를 우선한다. 활동 태그와 자산 배분 태그를 구별한다. 태그 없는 기록도 있으므로 태그 검색만으로 자료 부재를 단정하지 않는다.
- 도구 설명의 태그 OR/AND·기간·페이지 조건을 따른다. 지원하지 않는 필터를 만들어 넣지 않는다. 여러 조회가 필요하면 기록 ID로 중복을 제거한다.
- 결과의 검색 방식·fallback·색인 상태를 확인한다. 비었거나 무관하면 다른 표현/핵심어, 검색어 없는 관련 태그 조회로 보완한다. 자동으로 지나치게 좁힌 조건은 완화하되 사용자의 명시적 범위와 권한은 지킨다.
- 같은 검색을 끝없이 반복하지 않는다. 보완 후에도 근거가 부족하면 확인한 범위와 누락 가능성을 밝힌다. 검색 점수는 진실성이나 투자 정답 확률이 아니다.

## 비교하고 답하기

이론의 적용 조건과 반대 근거를 현재 상태에 대조한다. 충돌하는 근거는 우선한 이유를 밝히고 같은 주장을 반복한 글을 독립 증거로 중복 계산하지 않는다. 현재 외부 정보가 결론에 필요하면 이용 가능한 웹 검색으로 확인한다. 조사 실패·미확인 범위를 숨기거나 “변화가 없다”는 근거로 삼지 않는다.

사실, 사용자 선택, 에이전트 해석과 미확인 가정을 구별한다. 기록에 없는 보유 이유를 과거 사실처럼 추측하지 않는다. 질문에 맞게 결론과 실제 읽은 기록의 제목·ID/제공된 링크, 핵심 근거, 현재 상황과의 연결, 반대 조건·재검토 조건을 설명한다. 링크를 만들어내거나 읽지 않은 원문을 인용하지 않는다.

## 먼저 제안하고 동의 후 기록

스킬 본문의 답변 종료 기준으로 제안 여부를 판단한다. 새 전략과 이유, 기존 판단을 바꾸는 근거, 재사용할 이론 정리, 뉴스의 포트폴리오 영향, 구체적인 재검토 조건이 기록 후보에 해당한다. 현상 유지라도 새로 확인한 근거가 의미 있으면 제안할 수 있다. 기록할 가치와 사용자 채택 여부는 구별한다. AI가 만든 새 관리 기준은 미채택 검토안으로 남길 수 있으며, 기록 동의만으로 현재 원칙을 바꾸지 않는다.

대화에 보여 주는 초안은 사용자가 저장할 내용을 이해하고 승인할 수 있을 만큼 간결하게 쓴다. 아래 항목을 모두 별도 칸으로 늘어놓을 필요는 없지만, 동의 뒤 내용을 임의로 확장하거나 결론의 상태를 바꾸지 않는다.

- 무엇을 검토하고 알게 되거나 결정했는지 드러나는 제목·요약과 상세 본문. [활동 작성 지침](activities.md)에 따라 상단에 핵심 개념·대상·중요 조건을 담는다.
- 당시 읽은 이론/뉴스/결정의 제목·ID/실제 링크, 적용한 주장과 한계, 필요한 데이터 기준 시각.
- AI 검토안인지, 사용자가 채택했는지, 실제 변경 결과인지 구분한 결론.
- 중요한 반대 근거·불확실성·재검토 조건과 기존 태그·관련 시장 티커. 새 태그가 필요하면 새로 만들려는 것임을 함께 표시.

모든 기록에 동일한 양식을 강제하지 않는다. 원본 링크만 남기지 말고 나중에 판단을 이해할 당시 주장·이유를 본문에 보존한다. 원본이 수정돼도 과거 판단 본문을 자동 갱신하지 않는다.

초안에 동의하거나 구체적으로 저장을 요청하면 관련 기존 기록을 확인하고 `record_manual_activity`로 한 번 저장한 뒤 `get_activity`로 확인한다. 자동 활동이 이미 담은 사실은 중복 저장하지 않는다. 기존 판단의 정정 요청은 현재 원문을 읽고 `update_activity`로 승인 범위만 고친다. 새로운 시점의 다른 판단과 단순 정정을 구별한다.

후속 할 일이나 원칙 변경도 요청됐다면 해당 참고 문서의 절차를 함께 따른다. 판단 저장 성공 뒤 할 일 저장만 실패했다면 두 결과를 구분하고 성공한 저장을 반복하지 않는다.
