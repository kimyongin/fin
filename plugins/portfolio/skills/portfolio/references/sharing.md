# 공유·친구

공유는 포트폴리오 전체의 읽기 전용 범위다. 자산·배분·원칙·활동 등을 연결된 사람이 읽을 수 있으며 기능별 공유 스위치를 가정하지 않는다. 인증 비밀·친구 목록·제품 피드백까지 공개하는 것은 아니다.

내 설정은 `get_sharing_profile`로 읽는다. `save_sharing_profile`은 요청한 공개 이름·공유 여부·선택적 새 비밀번호를 저장한다. 빈 비밀번호는 기존 값 유지라는 계약을 따른다. 비밀번호나 해시를 읽어낼 수 있다고 하지 않는다. 아이콘 변경은 요청된 `set_profile_avatar`로 처리한다.

공유 초기화는 `reset_sharing_profile`이며 공개 이름/비밀번호 제거·공유 끄기·들어오는 연결과 열람 세션 해제의 영향을 확인하고 명시적 승인 후 실행한다. 포트폴리오 데이터·로그인 계정 삭제와 구분한다. 잊은 비밀번호는 조회하지 못하며 소유자가 새 값을 설정해야 한다.

친구는 `list_friends`로 실제 대상을 확인한다. 사용자가 제공한 친구 공개 이름/비밀번호와 연결 요청이 있으면 `connect_friend`를 쓰고, 연결 해제 요청에는 해당 관계의 `remove_friend`를 쓴다. 친구의 투자 데이터를 삭제하는 작업이 아니다. 비밀번호·토큰은 답변이나 기록에 반복하지 않는다.

선택한 친구 자료는 목록에서 얻은 소유자 ID로 `get_shared_portfolio_state`를 호출한다. 소유자 ID는 읽기 선택값이며 쓰기 권한이 아니다. 내 포트폴리오 조회 도구의 응답과 친구의 값을 혼동하지 않는다.

내 자료를 보는 연결 목록은 `list_portfolio_viewers`로 확인한다. 마지막 웹 열람 시각이 없다고 다른 경로에서도 한 번도 안 봤다고 단정하지 않는다. 공유 쓰기의 결과가 불확실하면 현재 설정/관계를 먼저 재조회한다. 공유 끄기·초기화·연결 해제 후에는 이전 접근이 거부되는지 확인한다.
