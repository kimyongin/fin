# ADR-0007 — 활동 중심 결과와 태그·복합 검색

2026-09-23 후속: [ADR-0008](../adr/0008-minimal-portfolio-storage.md)과 저장 단순화 #86~#91이 충돌하는 저장/이력/기능 유지 요구를 대체한다. 기존 구현·검증 증거와 미검증 외부 게이트는 보존하며 새 구현은 docs/START-HERE.md에서 시작한다.

상태: Accepted (과설계 축소 반영) · 2026-09-23. 구현 전.

## 결정

사용자는 활동 하나로 할 일과 한 일을 관리한다. 판단 모아보기 탭과 등록 경로별 라벨을 제거하고, 결론/이유는 활동의 선택 내용으로 읽는다. 모델 제안과 사용자가 채택한 의견은 구분한다.

기존 portfolio_tasks와 activity_events를 재사용한다. 한 일의 제목·결과·판단은 activity_events의 같은 레코드에서 관리한다. 앞서 제안한 activity_results/event_result 분리는 철회한다. 모든 이벤트가 불변이어야 한다는 전제도 사용하지 않는다. 필드 배치와 최소 API는 #80에서 확정한다.

수동으로 기록한 제목·수행일·내용·결론은 일반 편집으로 수정한다. 자동 금융 이벤트의 거래·수량·변경 전후 값·발생시각·원본 참조는 일반 편집으로 바꿀 수 없고 설명/태그만 편집한다. 금융 원본은 기존 목적별 정정 절차와 안전장치를 유지한다.

일반 메모·태그 편집마다 수정 이벤트나 이력 테이블을 추가하지 않는다. 필요한 updated_at/최소 충돌 검사와 기존 쓰기 규약을 사용한다. 기존 금융·태스크·과거 판단 이력은 보존하되 모든 일반 편집의 새 이력을 요구하지 않는다.

기존 event.task_id는 수행 대상/관련 태스크, 선택적 task.origin_event_id는 후속 할 일이 생긴 직접 계기를 나타낸다. 동일 사용자 참조를 검사한다. 연결 상대 상태의 자동 변경과 범용 관계 엔진은 도입하지 않는다.

사용자가 기존 활동을 편집하면 수정하고 새 활동을 추가하면 새 기록을 만든다. 시스템의 '설명 정정/새 판단' 자동 분류, 강제 대체 연결, 새로운 판단 상태 전이 엔진은 도입하지 않는다. 기존 판단의 상태/대체 관계/당시 근거는 이관 시 보존하고 관련 연결은 필요할 때만 사용한다.

## 검색과 전환

선택적인 다중 활동 태그는 자산 카테고리/배분과 분리한다. 기간·대상·상태·태그 조건과 키워드 검색을 먼저 제공하고 의미 검색을 같은 검색창에 추가한다. 임베딩은 최신 활동 내용에서 재생성할 수 있는 파생 데이터다. 검색용 임베딩의 공급자·품질·비용은 #83에서 검증하며 뉴스 조사/의견 생성은 ChatGPT가 담당한다.

활동 편집 후 최신 검색 내용과 임베딩을 갱신한다. 리포트는 저장 당시 요약을 유지하고 원본 변경 시 updated_at 등 최소 기준으로 재생성 필요를 표시한다. 별도 결과 revision 관리나 감사 이벤트 생성을 이를 위해 도입하지 않는다.

ADR-0006의 기존 반복·완료/재개·금융 원자 기록을 재사용한다. 활동 공유가 비공개 결론·태그 공개로 확대되지 않게 한다. 신규 판단은 활동 내용으로 제공하며 기존 investment_decisions의 이관/호환·물리 정리 시점은 #80에서 검증한다. 기존 테이블 삭제는 첫 기능의 선행조건이 아니다.
