# ADR-0008 — 현재값·활동 중심의 최소 저장 구조

상태: Accepted (방향과 축소 범위) · 2026-09-23. 이 문서는 날짜별 결정 이력을 보존한다. 현재 제품 계약은 [PRD](../prd/portfolio.md), 실제 적용 상태는 [배포 기록](../engineering/deployment.md)과 각 티켓을 따른다.

아래 초기 결정 중 보유 메모는 [#124 종목 메모 통합](../tickets/ui-17-asset-detail-simplification.md), 상세 시세 수정은 [#139](../tickets/ui-28-instrument-registration-and-quote-display.md), 기능별 공유는 [ADR-0009](./0009-whole-portfolio-sharing.md)가 대체한다. 후속 결정으로 대체된 문장을 현재 구현 요구로 복원하지 않는다.

## 배경

여러 번의 화면 통합 뒤에도 판단/보유 이유/자료/브리핑/리포트의 개별 원본과 이력·관계·영수증이 남았다. 사용자 요구는 현재 보유값과 메모, 원칙, 할 일과 활동을 쉽게 관리하는 것이다. 회계 원장과 모든 과거 상태 복원은 목적이 아니다.

## 결정

[단순성 원칙](../engineering/SIMPLICITY.md)을 개발·리뷰 기본으로 삼고 [재설계](../design/minimal-portfolio.md)를 적용한다.

- 계좌·종목·보유·가격·카테고리 배분 기반은 유지한다.
- 보유 이유는 기존 보유 메모로, 종목 공통 설명은 종목 메모로 관리한다.
- 판단·자료·점검·회고의 새 정본은 편집 가능한 활동이다. 작은 출처/범위/기간 정보는 해당 활동에 둔다.
- 할 일은 한 모델/공통 상태로 운영한다. 일반/조사/실행별 상태 엔진과 자동 체결 진행률은 축소한다. 매일 반복은 유지한다.
- 서술형 개인 기준·운영 규칙은 공통 원칙으로 관리하고 계산 가능한 목표 비중은 유지한다.
- 매매는 현재 보유값 계산과 활동 저장, 보정은 절대값 수정과 활동 저장이다. 과거 기록 편집으로 현재 잔고를 자동 재생하지 않는다. 수수료·세금 제외 체결가 평균 정책은 유지한다.
- 일반 편집의 불변·의무 이력·별도 revision과 상시 문맥 저장을 제거하는 방향으로 전환한다.
- 자동 금융 사실의 일반 텍스트 편집은 차단한다. 정밀 계산·원자성·중복 방지·자산 충돌 검사는 유지한다.
- 모든 기존 이력은 이관 또는 읽기 가능한 보관으로 보존한다. 개인정보의 기존 비공개 경계를 축소하지 않는다.

## 대체와 한계

2026-09-24 활동 후속 결정: [#122](../tickets/activity-15-tags-and-references.md)에 따라 활동의 내부 종류와 종류별 공유·본문 편집 제한을 제거한다. 내용 분류는 자유 태그, 관련 대상은 명시적 참조로 관리한다. 기록 편집/삭제는 실제 금융/할 일 상태에 영향을 주지 않으며 금융 명령의 원자성·정밀도·멱등성은 유지한다. 기존 활동 공유는 전환 시 차단 후 사용자 재설정으로 열며 비공개 필드를 자동 기록에 복제하지 않는다. 위 최소 자동 분류·자동 금융 본문 불변 요구를 대체한다. 이후 전체 공유 계약은 ADR-0009가 우선한다.

2026-09-24 배분 후속 결정: [#121](../tickets/ui-14-tag-allocation.md)에 따라 목표를 사용자별 자산 태그와 비중으로 단순화한다. 모드/버킷/태그 연결 저장소 및 적립금·매매 한도 기반 추천 계산을 제거한다. 필요한 계산은 태그별 현재/목표/차이며 의견은 ChatGPT가 담당한다. 모호한 다중 태그 목표는 임의 분할하지 않고 재설정한다. 적용과 검증 기록은 해당 티켓 및 배포 기록을 따른다.

2026-09-24 변경 이력 표현 보완: #118은 선택적 변경 메모를 기존 원칙 변경 행에 본문과 함께 저장한다. 날짜·메모로 탐색하고 선택 시 당시 본문 전체를 읽는다. 별도 메모 저장소·줄 DIFF·이전/이후 본문 쌍 표시는 추가하지 않는다. 이력 메모는 현재 지킬 원칙이 아니다.

2026-09-24 후속 결정: [#118](../tickets/ui-11-markdown-principles.md)에 따라 원칙의 사용자 데이터는 자유 마크다운 본문으로 단순화한다. 분류(kind)·적용 범위(scope) 및 이에 의존한 도구 계약을 제거한다. 한 원칙 항목에 여러 기준을 쓸 수 있으며 한 문장씩 분리할 의무는 없다. 아래 동일 테이블 원칙 이력 예외는 유지한다. 실제 스키마 전환과 검증은 해당 티켓 및 배포 기록을 따른다.

원칙 이력 예외(2026-09-24 후속 #132): 사용자별 현재 문서는 하나이며 같은 principles 테이블에 변경마다 본문·메모·서버 시각을 새 행으로 추가한다. 최신 저장본만 현재로 조회하고 과거는 읽기 전용 이력으로 본다. 원칙 ID별 다중 현재 문서/개별 종료 방식은 퇴역한다. 별도 이력 테이블·버전 번호·다른 데이터의 과거 상태 복원은 추가하지 않는다. 기존 여러 문서의 선택·보존과 서버 계약은 [단일 원칙 티켓](../tickets/principles-01-single-current-document.md)을 따른다.

반복 후속 #133: 기존 매일/오늘 회차 계약을 매일·선택 요일·시간과 최신 미처리 도래 회차로 확장한다. 사용자의 비정기 에이전트 요청이 실행 계기이며 누락 회차를 모두 재생하지 않는다. 기존 할 일/활동을 재사용하고 별도 스케줄러·큐·회차 테이블은 만들지 않는다. 구체적인 최소 계약·검증은 [반복 티켓](../tickets/activity-18-agent-due-recurrence.md)에 있다. 아래 오늘 완료 문구는 이 범위에서 대체되며 자동 실행 승인이 아니다.

초기 추가 결정(활동 자동 분류는 위 #122, 반복 회차는 #133으로 대체): 활동은 최소 분류를 자동 지정한다. 기록 삭제는 보유값/할 일 상태를 되돌리지 않으며 할 일 삭제도 기존 수행 기록을 지우지 않는다. 반복은 오늘 완료와 전체 종료/삭제만 구별하고 일시정지·재개 기능을 두지 않는다. 원칙은 한 행에 하나씩 저장한다. 최신 매매를 포함한 되돌리기는 제외하고 증권사 현재값으로 보정한다. 세부 과거 수정 과정은 백업/내보내기로 보존하며 복원 UI/API는 만들지 않는다.

ADR-0002의 과거 거래 취소/기준점 이후 재생, ADR-0004의 도메인별 의무 이력, ADR-0005~0007의 판단·보유 이유·리포트 별도 정본과 금융 원장 유지 요구 중 충돌 부분을 대체한다. ADR-0001의 역할 분리는 유지한다. 당시 유지한 ADR-0003의 기능별 공유 확장성은 이후 ADR-0009가 대체한다.

기존 이력 보존은 기존 테이블/API 영구 운영을 뜻하지 않는다. 반대로 새 설계 승인만으로 실제 테이블 삭제·운영 배포가 완료되거나 승인된 것은 아니다. 운영 적용 범위와 백업/복구는 릴리스 티켓에서 명시한다. 과거 티켓의 로컬 완료 증거와 미검증 외부 게이트는 유지한다.

2026-09-23 최종 후속 결정: 사용자는 기존 투자 데이터 전체를 삭제해도 된다고 명시했다. 구 데이터의 이관·과거 조회·기존 세션 호환을 이유로 별도 테이블/API/화면을 남기지 않는다. 인증·다중 사용자 격리·새 공유 설정 기능의 구조는 유지하되, 기존 투자 기록과 구 공유 대상 행은 폐기 가능하다. 이는 운영 DB 즉시 삭제/배포 지시와는 구분한다. 기존 이력 보존을 요구한 위 문장은 이 결정으로 대체한다.
