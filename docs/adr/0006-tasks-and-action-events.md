# ADR-0006 — 태스크와 자동 행동 이벤트의 통합 경험
상태: Accepted (제품 개념), 2026-09-22. 구현 완료를 의미하지 않는다.

[설계](../design/tasks-and-events.md)를 기준으로 ADR-0005의 번들/항목 모델과 별도 활동 탭 중심 경험을 대체한다. ADR-0005의 기존 메모 재사용과 독립 운영 규칙은 유지한다.
태스크는 예정/현재 상태, activity_events는 수행 사실을 관리하며 화면에서는 하나의 행동 목록으로 제공한다. 사전 태스크 없는 편집은 자동 이벤트만 남기고 완료 task를 별도로 만들지 않는다.
태스크 완료는 원본 task를 참조하는 이벤트를 남긴다. 재개해도 과거 사실은 보존한다. 매일 반복 일반 task는 회차별 유효 완료 이벤트로 판정하며 task를 매일 복제하지 않는다.
배열 저장은 편의 API로 유지할 수 있으나 bundle_id라는 영구 소속을 요구하지 않는다. 일/주/월 리포트는 요청 시 원본 기간 기록을 근거로 작성한다.
ADR-0004의 도메인별 저장과 최소 공통 규약을 유지한다. 범용 이벤트 소싱 엔진으로 금융 모델을 다시 만들지 않는다. 변경과 이벤트는 원자적으로 기록하고 공유 권한도 원본에 맞춰 검사한다.
