# ADR-0002 — 체결가 평균·절대 보정 기준점·선택적 공유

2026-09-23 후속: [ADR-0008](../adr/0008-minimal-portfolio-storage.md)과 저장 단순화 #86~#91이 충돌하는 저장/이력/기능 유지 요구를 대체한다. 기존 구현·검증 증거와 미검증 외부 게이트는 보존하며 새 구현은 docs/START-HERE.md에서 시작한다.

상태: Accepted (사용자 정책 3건, 2026-09-20). 상세 스키마·UI·보안 검증은 별도다.

## 배경

간단한 매매 입력으로 수량과 평균가를 관리하되 증권사와 완전한 원장 일치를 목표로 하지 않는다. 사용자가 현재 잔고를 직접 맞춘 보정의 의미와 새 정보의 공유 범위를 확정해야 했다.

## 사용자 결정

1. 평균가는 수수료·세금을 제외한 체결가 기준으로 계산한다. 증권사 값과 다르면 보정할 수 있다. 비용을 포함한 증권사 총수익과 같다고 주장하지 않는다.
2. 실제 값으로 보정한 기준점보다 이전 거래를 추가·취소해도 그 기준점이 정한 잔고는 유지한다. 과거 기록의 정정과 현재값 변경을 분리한다.
3. 새 개인 성향·판단·브리핑·할 일도 선택적으로 공유할 수 있어야 한다. 기존 자산·전략·뉴스 공유는 유지하고 새 정보는 자동 공개하지 않는다.

## 배제한 대안

- 수수료 포함 원가: 입력 부담을 늘리므로 첫 버전에서 제외한다.
- 과거 거래 정정이 최신 보정값을 덮어쓰기: 증권사와 맞춘 현재 잔고가 다시 바뀌므로 제외한다.
- 새 정보의 영구 소유자 전용: 사용자의 선택적 공유 요구와 다르므로 제외한다. 기본 비공개는 유지한다.

## 영향과 검증

- #32/#37/#38: 체결가 평균 계산 예제, 기준점 이전/이후 재계산, 후속 거래 초과 매도 및 취소 테스트를 정의한다.
- #43/#44: 새 개인 데이터 저장은 기존 공유 전략 JSON과 분리한다. 허용 데이터와 참조/본문의 공개 범위를 정의한다.
- #36/#39: 공개 미리보기·읽기 전용·권한 철회·직접 링크/검색/CSV 누출을 검증한다.
- 공유 구조는 후속 [ADR-0003](./0003-extensible-feature-sharing.md)을 따른다. 기능별 권한을 내부에 두고 설정 화면은 묶음으로 단순화한다. 친구별 예외와 개별 문서 ACL은 첫 버전 범위 밖이다.
- ADR-0001의 기본 비공개 정책을 유지하면서 명시적 선택 공유를 구체화한다. 기존 문서의 ‘소유자 전용’은 기본 상태로 해석하고 선택 공유 기능 자체를 배제하지 않는다.

DB·앱 변경은 아직 수행하지 않았다. 이 ADR이 마이그레이션이나 공유 보안 검증 완료를 뜻하지 않는다.
