## 현재 기준

- ChatGPT는 조사·해석·설명, Portfolio는 기억·계산·검증한다.
- 계좌/종목/보유/카테고리 비중과 유용한 기존 자산 편집은 유지한다.
- 보유 이유는 메모, 조사/판단/점검/회고는 활동, 예정/반복은 할 일, 서술형 기준은 원칙으로 단순화한다.
- 일반 편집의 불변/revision/의무 이력/변경 사유는 제거한다. 금융 중복 방지·원자성·정밀 계산·사용자 격리는 유지한다.
- 현재값 직접 보정으로 금융 기능을 축소하며 과거 거래 자동 재생은 요구하지 않는다.
- 최신 매매도 되돌리기 없이 증권사 현재값으로 보정한다. 반복은 오늘 완료와 전체 종료/삭제만 구분하고 일시정지/재개는 없다. 기록 삭제는 잔고/할 일 상태를 되돌리지 않는다. 새 활동은 종류 대신 태그와 대상 참조를 사용하고, 원칙은 자유 마크다운 본문과 변경 메모를 저장한다. 세부 과거 포트폴리오 복원 기능은 만들지 않는다.
- 통합은 기존 비공개 정보를 공개할 권한이 아니다. 필드별 공유 경계를 검증한다.
- 2026-09-23 최신 사용자 결정: 기존 투자 데이터 전체는 삭제해도 된다. 재입력·재사용을 전제로 레거시 행 이관/읽기 호환을 완료 조건으로 두지 않고 구 저장소·API·화면을 정리한다. 인증, 사용자 격리, 다중 사용자용 공유 기능의 구조는 유지한다. 운영 DB 적용·배포는 개발과 별도 게이트다.

## 다음 작업과 상태

모든 모달의 최신 공통 규칙: [모달 가이드](./design/modal-guidelines.md)에 따라 현재 대상의 수정 가능한 속성은 상세에서 바로 편집하고 한 번에 저장한다. 별도 수정 모드·속성별 모달·같은 대상의 태그 별도 저장은 제거한다. 전수 적용은 [#123](./tickets/ui-16-modal-inline-edit.md), 자산은 #120과 함께 담당한다. 읽기 전용/과거 이력은 그대로 읽기 전용이며 현재는 설계·구현 대기다.

활동 최신 설계: [#122](./tickets/activity-15-tags-and-references.md). 활동 내부 종류를 완전히 제거하고 날짜·제목·본문·태그·대상 참조로 단순화한다. 종류별 공유는 활동 공유 하나로 합치며 기존 활동 관련 허용은 전환 시 해제 후 사용자가 다시 켠다. 기록 수정/삭제는 잔고/할 일 상태를 되돌리지 않는다. 위의 최소 자동 분류 및 기존 종류별 보호 요구를 대체하는 설계이며 구현 전이다.

배분 단순화 설계: [#121](./tickets/ui-14-tag-allocation.md). 모드·버킷과 적립금/한도 기반 추천 계산을 제거하고 태그별 현재/목표/차이를 한 목록에서 직접 편집한다. 별도 배분 설정 화면은 없애며 목표 숫자·태그·공유 경계는 유지한다. 기존 문서의 계산 한도 유지 요구보다 우선한다. 구현 전이다.

자산 상세 단일 편집 공간: [#120](./tickets/ui-13-asset-detail-inline-edit.md). 종목 공통/계좌별 속성을 상세 안에서 직접 수정하고 일반 변경은 한 번에 원자 저장한다. 매매·증권사 확인 등 별도 행동은 같은 shell 안에서 단계 전환한다. #113의 상세→별도 편집 모달 왕복을 대체하는 설계이며 구현 전이다. 저장 계약을 먼저 확정한다.

## 문서와 인계

충돌 범위는 ADR-0008과 새 재설계/티켓이 우선한다. 현재 [PRD](./prd/portfolio.md)와 [백엔드 경계](./engineering/backend-modules.md)는 과거 계획을 분리했다. 과거 원문은 각 문서가 연결한 `docs/history/`에 보존하며, 폐기 구조의 재구현 지시로 읽지 않는다. [이전 시작점 원문](./history/start-here-before-storage-simplification.md)도 배경 이력이다.

종료 시 실제 완료/미완료, 변경 계약, 검사 결과, 다음 작업을 티켓에 남긴다. API 변경은 앱·MCP 설명·get_workflow_guide·검증과 함께 갱신한다. 문서만 수정한 것을 구현/배포 완료로 표시하지 않는다.
