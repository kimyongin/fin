# [자산 UX] 평균가·현재가·가격 수익률 표시와 목록 정돈

2026-09-24 · Astra 설계 · Sol 로컬 구현/자동 검증 · 운영 전 · P2

GitHub: https://github.com/kimyongin/fin/issues/129

후속 화면 계약: [#134 종목·보유·평가 3열](./ui-23-asset-list-columns.md). 아래 모바일 별도 숫자 행과 목록 내 시세 기준일 반복은 3열 헤더·셀 배치 및 상세의 기준일 조회로 대체한다. 계산·예외·권한과 기존 구현 기록은 유지한다. 후속 화면은 로컬 구현·자동 검증을 마쳤다.

## 목적과 현재 구현

보유 목록에서 내 매입 기준과 최신 시세를 비교한다. 자산은 보유 확인, 배분은 태그별 비중 확인을 책임진다.
`AssetsPage.jsx`의 상단 태그 비중 요약과 목록 읽기 칩을 정리한다. `usePortfolioDerivedData.js`에 계좌별/종목 합산 평균가·현재가·priceChangePercent 계산이 이미 있으므로 재사용한다.

## 범위

- 시장형 종목에 수량·내 평균가·현재가·가격 수익률과 평가금액을 보여준다. 모바일은 이름/코드·태그 뒤에 숫자 두 줄 등으로 배치하고 가로 스크롤이나 작은 글자로 밀어 넣지 않는다.
- 가격 수익률은 `(현재가 / 내 평균가 - 1) × 100`. 수수료·세금·배당·환율 수익을 포함한 총수익률이나 전일 등락률로 표현하지 않는다. 시세 기준일과 기존 누락/오래된 시세 상태를 유지한다.
- 전체 계좌는 종목별 수량 가중 평균, 계좌 선택 시 해당 계좌 평균을 사용한다. 계좌별 DTO와 종목 합산 DTO의 현재가 자료형 차이를 확인한다.
- 평균가/시세가 없거나 평균가가 0이면 수익률은 `—`; 0%로 꾸미지 않는다. 현금·직접평가형에 주식 현재가/가격 수익률을 억지로 붙이지 않고 기존 유형별 평가를 유지한다.
- 상단 태그별 비중 요약을 제거한다. 태그 연결·배분 탭·계좌 선택·검색·표 편집·상세 편집 기능은 유지한다.
- 목록 태그는 종목 코드 옆의 일반 보조 텍스트로 표시한다. 선택/관리의 칩은 유지한다. 태그 가이드가 #128의 일괄 읽기 칩 요구를 이 범위에서 대체한다.
- 새 DB/API/수익률 저장 컬럼은 만들지 않는다. 사용자 격리·공유 범위는 바꾸지 않는다.

## 완료 기준

- [ ] 전체/선택 계좌의 다른 매입가, 여러 통화, 양수/음수/0 수익률을 계산 fixture와 실제 목록으로 검증한다.
- [ ] 누락/0 평균가, 누락·오래된 시세, 현금·직접평가형·미분류·긴 이름을 확인한다.
- [ ] 360/390/768/1024/1440px에서 가격·기준일·태그를 읽을 수 있고 페이지 가로 넘침이 없다.
- [ ] 기존 목록→상세→저장·계좌 필터·표 편집과 공유 읽기 회귀를 확인한다.
- [ ] 관련 테스트·빌드·인코딩 검사 및 실제 검증/미검증 범위를 기록한다. 운영 배포는 별도다.

구현 순서: 기존 계산/DTO 대조 → 한 목록 소비자에 연결 → 반응형·회귀 검증. 코드 구현은 Sol에서 한다.

## 구현 기록 (2026-09-24)

기존 `usePortfolioDerivedData`의 계좌별/종목 합산 평균가와 시세 수익률을 목록에 연결했다. 태그 비중 요약을 제거하고 태그는 보조 텍스트로 보인다. 102개 unit, 575개 DB, 관련 27개 내비게이션·앱 브라우저 회귀와 21개 활동 회귀를 통과했다. 운영 배포·실기기 확인, 모든 가격/통화 조합의 화면 검증은 아직 완료로 간주하지 않는다.

### 2026-09-26 오래된 시세 경고 후속 수정

평가형·현금성은 직접 입력한 평가액을 사용하므로 같은 티커에 과거 가격 행이 남아 있어도 `stale_price`를 붙이지 않는다. 외화 평가액의 환산에 실제로 필요한 환율만 `stale_fx`로 판단하고, 0원 또는 아직 산출할 수 없는 금액에는 환율 경고를 붙이지 않는다. 이는 기존 서버 `app_get_portfolio_valuation_quality`의 판정과 같다. `resolvePositionValuation`에 해당 조건을 반영하고 시세형의 오래된 가격·외화 평가형의 오래된 환율은 유지했다. 전체 단위 테스트 21파일/107건, 빌드, 인코딩 및 diff 검사를 통과했다. 로컬 화면의 실제 사용자 자산에서 과거 가격 행을 재현하거나 운영 배포한 결과는 아니다.
