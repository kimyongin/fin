# [활동 검색] 저장 자료 기반 에이전트 검토와 웹·MCP 교차 검증

상태: 설계 완료 · 구현 전 · 2026-09-27
GitHub: https://github.com/kimyongin/fin/issues/164
선행: search-01~03. 기준: [검색 설계](../design/activity-context-search.md).

S4. “투자 이론 태그의 심리 관련 자료를 참고해 지금 해야 할 행동을 검토해줘”를 실제 OAuth 세션에서 수행한다.

- [ ] MCP 설명/가이드에 태그·종목 후보 해석→직접 자료 검색→필요 원문·연결 맥락→현재 원칙·자산·배분·진행 할 일 비교 흐름을 반영한다. 자연어 이해는 에이전트가 담당하며 앱에 별도 대화 분석 엔진을 추가하지 않는다.
- [ ] 미채택 이론·현재 원칙·과거 가정·현재 자산을 구별하고 반대 근거·적용 조건도 검토한다. 외부 최신 정보가 필요한 경우 확인 범위와 부족 정보를 명시한다.
- [ ] 답변에 읽은 기록의 제목·ID/실제 링크·핵심 근거와 제안 행동의 연결이 있다. 검색점수를 정답 확률로 쓰지 않고 저장 본문을 실행 지시로 따르지 않는다.
- [ ] 검색 실패/미색인/무관 결과를 자료 없음으로 단정하지 않는다. 연결 기록을 직접 검색 hit로 오해하지 않는다. 검토 요청만으로 원칙/할 일을 저장하지 않고 기존 할 일 중복을 확인한다.
- [ ] 한국어 합성 이론 자료로 단어 불일치·오래된 자료·긴 본문·연결 양방향·종목 일부·태그+기간·완료 할 일·상충 이론·오류 fallback을 웹 HTTP와 OAuth MCP 양쪽에서 교차 검증한다. 사용자 운영 본문을 코드/로그 fixture에 복제하지 않는다.
- [ ] 실제 모델 품질과 실제 ChatGPT 웹·모바일 검증을 mock/CI 통과와 구분한다. 확인할 수 없는 클라이언트 검증은 명시적으로 미완료로 남긴다.
- [ ] 운영 오류 수정, 색인 백필/모델 전환, 웹/Edge/DB 배포 순서·직전 정상 버전·복귀 절차를 기록한다. 인코딩·가이드 digest·Edge·DB·브라우저 및 인증된 운영 호환성 게이트를 통과한다.

새 조사/판단/이론 도메인이나 자동 매매·자동 저장을 도입하지 않는다. 각 선행 슬라이스에서도 관련 교차 검증을 수행하고 이 티켓을 마지막 테스트 몰아하기로 사용하지 않는다.
