## 목적과 근거

src/features/activity/ActivityEventViewer.jsx에 구 뉴스/번들/일시정지/실행계획 action label 및 repairMojibake가 남아 있다. 사용되지 않는 것으로 확인된 표시 코드만 제거한다. 이름이 오래됐다는 이유만으로 호환 코드를 없애지 않는다.

## 착수 조건

#91 운영 전환의 실제 상태와 남길 데이터/표시 요구를 확인한다. 운영에서 필요한 기록을 깨뜨릴 수 있으면 구현하지 않고 유지 사유를 기록한다. 이 티켓은 운영 DB 삭제·배포 권한을 포함하지 않는다.

## 범위와 완료 기준

- [ ] 각 후보의 현재 생산자·소비 데이터·호환 목적을 대조한다.
- [ ] 사용 종료가 입증된 label/분기만 제거하고 유지할 것은 이유를 남긴다.
- [ ] repairMojibake는 실제 인코딩 호환 수요를 별도 확인한 후 제거 여부를 결정한다.
- [ ] 현재 자동 자산 기록/수동 활동/미확인 action fallback/CSV 표시 회귀를 확인한다.
- [ ] 관련 단위·E2E·빌드·인코딩 검증과 삭제 목록을 기록한다.

새 저장 구조·데이터 삭제·migration 재작성은 제외한다. 제거 대상이 없으면 근거를 기록하고 변경 없이 종료 가능하다. 앞선 리팩토링이나 릴리스의 선행 조건으로 만들지 않는다. 구현·배포 미실시.
