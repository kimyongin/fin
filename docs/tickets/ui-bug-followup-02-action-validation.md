# 활동 추가 유형 전환의 숨겨진 필드 검증 수정

2026-09-23 · 로컬 구현·격리 검증 완료, 운영 배포 전 · #100 후속 버그.

## 재현 조건과 근거

GeneralActionModal.jsx의 저장 disabled 조건이 isTask와 관계없이 출처/채택 판단 필드를 검증한다. 이미 했음을 체크하고 출처 제목만 입력하거나 판단 → 내가 채택함을 선택한 뒤 이미 했음을 해제하면, 보이지 않는 필드 때문에 할 일을 저장할 수 없다. 코드 경로 확인 상태이며 브라우저 재현은 아직 하지 않았다.

## 범위와 완료 기준

- [x] 현재 유형의 입력만 저장 가능 여부와 payload에 반영한다. 숨겨진 초안을 유지할지는 UI 내부 결정으로 기록하되 잘못 전송하지 않는다.
- [x] 출처 부분 입력 → 할 일 전환 → 제목만으로 저장 가능함을 검증한다.
- [x] 채택 판단 필수값 미입력 → 할 일 전환 → 저장 가능함을 검증한다.
- [x] 이미 했음으로 돌아오면 출처/채택 판단의 기존 검증이 적용된다.
- [ ] 반복/예정일/태그/재시도 회귀와 390px/1440px 상호작용을 확인한다.

새 API/저장 구조/범용 검증 라이브러리는 필요 없다.

## 구현·검증 기록 (2026-09-23)

GeneralActionModal의 저장 가능 여부에서 현재 유형이 할 일일 때 숨겨진 출처·판단 필드를 검사하지 않게 했다. 저장 adapter는 원래부터 할 일 payload에 해당 필드를 넣지 않는다. `e2e/activity.spec.js`에서 부분 출처와 채택 판단을 입력한 뒤 할 일로 바꿔 저장 가능 상태를 확인했고, 다시 한 일로 돌아가면 필수 입력 검증이 적용되는 것도 확인했다. 격리 전체 실행의 해당 테스트는 통과했다. 운영 배포 및 실기기 확인은 하지 않았다.
