# [피드백] 운영자 검토와 처리 결과 연결

우선순위: P2 · 상태: 로컬 구현/자동 검증 완료 · 선행: #66, #67

## 범위

[공통 설계](../design/product-feedback.md)의 F06/F07을 구현한다.

- 피드백 페이지에서 운영자만 내 피드백/전체 접수 전환. 별도 주 메뉴나 대형 관리자 시스템은 추가하지 않음.
- 관리자 전용 목록/갱신 RPC, 상태 필터와 안정적 페이지 조회. received/reviewing/planned/resolved/deferred 상태 사용.
- 원문 보존, 상태·작성자 공개 답변·선택적 GitHub 링크 변경만 제공. 현재값은 CAS로 보호하고 필요한 최소 운영 기록만 남김. 공유 activity에 본문 노출 금지.
- 해결 처리에는 결과 설명 필수. 코드 수정 건은 실제 수정·배포 전 resolved로 표시하지 않음.
- 개발자가 공개 가능한 내용으로 GitHub 티켓 수동 작성/연결. 중복은 기존 이슈를 답변으로 안내. 원문 공개 기능은 없음.
- 검토된 사용상 주의는 익명화한 안내문으로 기존 가이드에 반영하는 절차 기록.

## 인수 조건

- [x] 일반 사용자의 관리자 호출·테이블 변경·역할 자기 승격 거부. 관리자에게 투자 데이터 권한이 생기지 않음.
- [x] 운영자 처리→작성자 앱/MCP 상태·답변 조회 검증.
- [x] 동시 갱신 충돌 시 기존 답변 덮어쓰기 없음. 상태 필터/페이지/빈 결과/오류 재시도 확인.
- [x] GitHub 링크는 허용된 HTTPS 이슈 URL만 처리하고 접수 원문을 외부에 자동 공개하지 않음.
- [x] 모바일/PC 공통 화면 규칙·DB/E2E/encoding 검증 및 운영 역할 관리 절차 완료.
