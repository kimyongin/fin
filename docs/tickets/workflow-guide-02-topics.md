# [MCP 가이드] 일일 점검과 판단·기록 작업 가이드 확장

우선순위: P1 · 상태: 로컬 구현·자동 검증 완료, 운영/모델 평가 대기 · 2026-09-21
선행: workflow-guide-01-policy · 관련 W01~W08

## 목적과 범위

[공통 설계](../design/contracts/agent/workflow-guide-design.md)의 holding_thesis, daily_review, decision_followup, trade_entry, reconciliation을 순서대로 추가한다. topic별 실제 도구 연결과 사례 검증이 끝나면 다음으로 이동한다.

- 기존 정책/도구를 안내하며 신규 도메인 기능을 이 티켓에 섞지 않는다.
- 보유 이유: 종목 공통/계좌 예외, 미입력 추론 금지, 선택적 기존 task 연결.
- 일일 점검: context 기반 조사, 이전 미확인 범위, 자료 부족/변화 없음 구별, 분석과 저장 의도 구별.
- 판단/후속: proposed/adopted, 조사 질문/실행 계획/체결 구별. 독립 질문 생성 미지원은 앱 또는 현재 지원 흐름으로 안내하며 허위 판단을 만들지 않는다.
- 실제 체결: 모호한 계좌 확인, preview→기록, 선택적 계획 연결. 계획 저장/취소가 체결 생성/취소가 되지 않는다.
- 정정: 보정/취소/실제 확인 분기, 보정 이전 기록의 현재값 유지, 순서 영향 확인.
- 기존 daily-review resource/prompt를 공통 가이드 원본과 연결해 별도 본문 중복을 제거한다.
