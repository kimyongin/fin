# [UI] 활동 화면 용어를 할 일·기록으로 통일

2026-09-24 · P2 · 로컬 구현 및 자동 검증. 사용자 합의: 상위 메뉴는 활동, 앞으로 수행할 작업은 할 일, 수행·조사·판단·자산 변경을 남긴 내용은 기록으로 표현한다.

GitHub: https://github.com/kimyongin/fin/issues/116

## 목적과 적용 기준

사용자가 할 일/한 일의 미묘한 표현 차이를 해석하지 않아도 예정된 작업과 저장된 내용을 구분하게 한다. 기존 데이터 모델과 저장 동작은 유지하고 사용자에게 보이는 명칭을 정돈한다.

| 현재 표현 | 적용 표현 |
| --- | --- |
| 활동 탭·활동 추가 | 유지 |
| 지금 할 일 | 할 일 |
| 날짜별 한 일 | 기록 (날짜별 묶음은 유지) |
| 원래 할 일 (#115의 상세 요약) | 관련 할 일 |
| 상세의 한 일 영역 | 기록 내용 |
| 한 일 입력 제목 | 기록 제목 |
| 한 일의 활동 상세 모달 제목 | 기록 상세 |
| 완료 기록에 표시하는 종류 ‘할 일’ | 할 일 완료 |
| 할 일과 한 일을 검색 | 할 일과 기록을 검색 |

- 기록에는 할 일 완료, 직접 입력한 조사·판단, 자동 자산 변경 등이 포함된다. 기록을 작성했다는 이유만으로 별도 할 일을 완료시키지 않는다.
- ‘할 일 완료’는 완료 기록의 종류 배지에만 적용한다. 미완료 검색 항목은 ‘할 일’로 표시한다. 현재 종류 필터의 task는 미완료와 완료 기록을 함께 찾으므로 필터는 ‘할 일’을 유지하고 필요한 짧은 설명으로 범위를 알린다. 이름 교체를 이유로 검색 조건을 바꾸지 않는다.
- 활동 추가의 ‘이미 했음’은 저장 방식을 선택하는 행동 문구로 유지한다. 선택 시 입력 제목/설명에 기록 용어를 사용한다. 용어 정리만을 위해 새 탭이나 등록 버튼을 늘리지 않는다.
- 상태·버튼은 의미에 맞게 쓴다. 할 일을 수행한 경우의 ‘완료’는 유지하고, 모든 조사·판단 기록에 할 일 완료를 뜻하는 표현을 일괄 붙이지 않는다.
- 메뉴/제목/폼/도움말/빈 상태/검색 결과/접근성 이름을 점검한다. 사용자가 작성한 본문과 과거 기록의 내용을 문자열 치환하지 않는다.

## 기존 구현과 작업 범위

- `ActionTimeline.jsx`: 목록 제목, 검색 안내, 미완료 검색 항목과 완료 기록의 표시.
- `ActivityDetailModal.jsx`: 기록 상세, #115의 관련 할 일·기록 내용 영역.
- `GeneralActionModal.jsx`, `GeneralTaskDetail.jsx`: 등록 입력과 안내 문구. 수행/기록 선택 의미는 유지한다.
- `activityKinds.js`, `ActivityKindBadge.jsx`, `ActivityEventViewer.jsx`: 완료 기록 배지와 종류 필터를 문맥에 맞게 표시한다. 하나의 공통 라벨 교체로 미완료 항목까지 ‘완료’라고 표시하지 않는다.
- 실제 화면에 노출되는 다른 안내와 테스트 선택자를 함께 점검한다. 코드 식별자·테이블·RPC·MCP 도구명·enum은 변경하지 않는다.
- PRD/화면 구조의 현재 용어와 #115 명세를 맞춘다. MCP의 한국어 사용자 안내에 영향을 주는 설명/가이드만 점검하고, 변경하거나 영향 없음 사유를 기록한다. 과거 설계 문서 전체를 재작성하지 않는다.

## #115와 관계

#115가 상세 구조·후속 연결 기능 축소를 담당하고 이 티켓은 표시 용어를 담당한다. 함께 구현하면 ‘관련 할 일 / 기록 내용’을 바로 적용한다. 각각 진행해도 검색·저장 동작을 바꾸지 않는다. #114 원칙 타임라인과는 독립이다.

## 완료 기준

- [x] 활동 화면의 두 목록이 ‘할 일 / 기록’으로 표시되고 날짜별 기록 묶음은 유지된다.
- [x] 상세·입력·검색·빈 상태의 사용자 문구와 접근성 이름에 같은 기준이 적용된다.
- [ ] 관련 할 일 없는 기록도 자연스럽게 읽히고, 미완료 할 일을 ‘할 일 완료’로 표시하지 않는다.
- [x] 등록 방식·완료 처리·반복·종류 OR 검색·태그·저장 데이터 의미를 유지한다.
- [ ] 관련 기존 UI 검증과 빌드·인코딩 검사를 수행한다. 360/390/768/1024/1440px에서 변경 문구가 넘치지 않는지 확인하고 미검증 범위를 기록한다.

목록·상세·입력·검색 결과의 표시 문구와 완료 기록 배지를 로컬 구현에 맞췄다. `task` 종류의 미완료 할 일은 ‘할 일’, 완료된 기록은 ‘할 일 완료’다. 데이터 저장·검색 조건·MCP 도구명은 변경하지 않았다. 360/390/768/1024/1440px 화면과 전체 E2E, 빌드·인코딩을 통과했으며 실기기·스크린리더와 운영 배포는 미검증이다.
