## 목적

U06. 다른 표현으로 과거 맥락을 찾는 검색을 보완한다.

## 인수 조건

- [x] Supabase pgvector 지원을 공식 문서로 확인하고 현재 규모에 맞는 최소 구현을 선택한다. 별도 검색 플랫폼/범용 큐 프레임워크를 선구현하지 않는다.
- [x] 한국어 fixture로 임베딩 모델·실행 위치·입력 범위와 fallback을 검증한다. Supabase Edge 내장 `gte-small`을 사용해 별도 공급자 키나 유료 API를 요구하지 않고, 실행 불가 시 기본 검색으로 동작한다.
- [x] 현재 활동 제목·메모·결론 등 검색에 필요한 내용만 임베딩한다. 비밀값이나 금융 감사 snapshot 전체를 전송하지 않는다.
- [x] 임베딩은 파생 데이터다. 내용 해시로 편집 후 갱신하고 오래된 작업이 최신 결과를 덮어쓰지 못하게 한다. 문서 revision/history 테이블을 요구하지 않는다.
- [x] 조건·권한을 적용한 키워드/의미 검색을 결합한다. 같은 검색창/MCP를 사용하고 첫 페이지·top-k 정책을 명시한다. 조건 밖 결과로 수를 채우지 않는다.
- [x] 인덱싱 지연/실패·재시도/백필을 검색 시 최대 12건 보완으로 처리한다. 기본 저장/조회는 계속 가능하며 `semantic_status`로 의미 검색 미실행과 결과 없음이 구분된다.
- [x] 유사도로 완료/채택/병합/판단 유효성을 결정하지 않는다. 기존에 기록된 상태와 참조만 보여준다.
- [x] 한국어 활동 fixture로 순위·편집 후 stale 제외·오래된 작업 거절·조건·타인 정보 차단을 검증하고 #84 가이드에 fallback 의미를 반영한다.

## 실행 기준

`activity_embeddings`는 현재 활동 내용에서 언제든 다시 만들 수 있는 1:1 파생 projection이다. 검색 서비스·범용 작업 큐·외부 임베딩 API는 도입하지 않았다. 로컬 구현과 자동 검증은 완료했지만 운영 DB/Edge/앱 배포와 실제 ChatGPT 웹·모바일 평가는 별도 릴리스 단계다.
