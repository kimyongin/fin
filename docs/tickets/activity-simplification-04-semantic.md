# [활동 단순화] 조건·키워드·유사도 하이브리드 검색

상태: 단순화 반영 · 구현 전 · 2026-09-23
GitHub: https://github.com/kimyongin/fin/issues/83
선행: 03 기본 검색. 02/03 릴리스를 차단하지 않음.
기준: [공통 설계](../design/activity-simplification.md), [ADR-0007](../adr/0007-activity-results-and-search.md).

## 목적

U06. 다른 표현으로 과거 맥락을 찾는 검색을 보완한다.

## 인수 조건

- [ ] Supabase pgvector 지원을 공식 문서로 확인하고 현재 규모에 맞는 최소 구현을 선택한다. 별도 검색 플랫폼/범용 큐 프레임워크를 선구현하지 않는다.
- [ ] 한국어 fixture로 임베딩 모델·실행 위치·입력 범위·품질/지연/비용을 검증한다. ChatGPT 구독과 API 비용을 구분하고 공급자/키가 없으면 기본 검색으로 동작한다. 추가 유료 서비스는 무단 가입/결제하지 않는다.
- [ ] 현재 활동 제목·메모·결론 등 검색에 필요한 내용만 임베딩한다. 비밀값이나 금융 감사 snapshot 전체를 전송하지 않는다.
- [ ] 임베딩은 파생 데이터다. updated_at 또는 내용 해시 등 최소 기준으로 편집 후 갱신하고 오래된 작업이 최신 결과를 덮어쓰지 못하게 한다. 문서 revision/history 테이블을 요구하지 않는다.
- [ ] 조건·권한을 적용한 키워드/의미 검색을 결합한다. 같은 검색창/MCP를 사용하고 관련도 정렬·날짜·top-k/페이지 정책을 명시한다. 조건 밖 결과로 수를 채우지 않는다.
- [ ] 인덱싱 지연/실패·재시도/백필을 최소 운영 절차로 처리한다. 기본 저장/조회는 계속 가능하며 의미 검색 미실행을 관련 기록 없음으로 표현하지 않는다.
- [ ] 유사도로 완료/채택/병합/판단 유효성을 결정하지 않는다. 기존에 기록된 상태와 참조만 보여준다.
- [ ] 한국어 정답 활동 fixture로 기본 검색 대비 검색 품질·누락·지연·비용과 편집 후 갱신·타인 정보 차단을 검증하고 #84 가이드에 실제 제공 상태를 반영한다.

## 실행 기준

기존 구조를 활용해 필요한 최소 변경을 사용자 기능 단위로 구현한다. 일반 활동에 불변성·별도 결과 저장·의무 수정 이력을 도입하지 않는다. 금융 원본/계산/인증/권한과 기존 재시도·반복 동작은 유지한다. 이번 갱신은 설계·티켓만 변경하며 구현·배포 완료를 뜻하지 않는다.
