# [제품 리뷰] 판단·할 일 통합과 미완료 과제 연속 조회

상태: 구현·로컬 검증 완료 · 운영 배포/실사용 확인 전 · 2026-09-21
상위: #40. 기존 책임: #35/#36/#44. 선행: 공유 접근 단계.

## 문제와 시나리오

S09~S14/S16/S24: 최근 갱신 20개에 밀린 오래된 미완료 과제가 사라지고, 판단에서 연결된 과제로 이동할 수 없다. 사용자는 왜 생긴 과제인지 다시 찾아야 한다.

## 범위와 계약

- 하나의 판단·할 일 화면에 할 일/판단 기록 탭을 제공한다. 기본은 미완료 할 일이다.
- 조사 open/waiting과 실행 planned/partial을 구분해 서버에서 필터/페이지 처리한다. 보류/종료 기록은 별도 필터로 조회한다. 앞 20개를 가져온 뒤 프런트에서만 필터링하지 않는다.
- list/get_portfolio_task, list/get_investment_decision 및 공유 DTO를 활용한다. API 변경은 동률 timestamp에서도 누락 없는 안정적인 cursor를 포함하고 기존 MCP 호출 호환성을 보존한다.
- 판단↔과제, 허용된 브리핑/종목/체결 관계를 상세에서 탐색한다. 관계가 없으면 추론해서 만들지 않는다. 공유에서 허용되지 않은 관계는 열거나 제목을 유출하지 않는다.
- 목록 위치/필터와 상세 뒤로가기를 보존한다. 기존 #tasks/#decisions 주소는 해당 탭으로 연결한다.
- 조회/탐색이 판단 채택·과제 완료·체결 기록·보유량을 변경하지 않는다. 단순 상태 변경 UI가 필요하면 기존 transition API와 사용자 의도를 사용한다.

## 완료 증거

관련 SQL/API/화면 E2E 결과와 실제 확인 폭을 기록한다. 기존 #35/#36/#44의 충족 항목만 근거와 함께 갱신한다.

- migration 022는 할 일과 판단에 서버 필터와 `(updated_at,id)` 커서를 제공한다. 미완료 할 일은 조사 `open/waiting`과 실행 `planned/partial`만 포함하며 보류·종료는 별도 필터다.
- migration 023은 브리핑 이력에도 `(analyzed_at,id)` 커서를 제공한다. 세 페이지 API 모두 소유자/공유 권한을 확인하고 허용되지 않은 연결 제목을 반환하지 않는다.
- 판단/할 일은 하나의 화면 안에서 탭으로 전환한다. 기존 `#decisions`, `#tasks` 주소는 유지하고 필터별 스크롤 위치, 상세 간 이동과 이전 기록 복귀를 보존한다.
- DB fixture는 동일 시각 미완료 할 일 57개, 현재 판단 55개, 브리핑 55개를 두 페이지로 조회해 누락·중복이 없음을 확인한다. 계획/부분 체결, 보류, 종료, 잘못된 커서도 검증한다.
- `npm run test:db`: 18개 SQL 파일, 259 assertion 통과.
- `npm test -- --run`: 13개 파일, 57개 테스트 통과.
- `E2E_PORT=4180 npm run test:e2e`: 24개 통과. 판단→연결 과제→판단 복귀, 종료 필터, 키보드 진입, 오류 재시도, 공유 철회, 긴 제목과 360/390/768/1024/1440px 가로 넘침을 확인했다.
- `npm run build`, `npm run check:encoding`, `git diff --check` 통과. 운영 migration/배포와 실제 계정 확인은 아직 수행하지 않았다.
