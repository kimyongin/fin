# [제품 리뷰] OAuth 온보딩과 실제 사용자 흐름 검증

상태: 로컬 구현 완료·외부 검증 대기 · 2026-09-21
상위: #40. 기존 책임: #33/#36/#39. 선행: 메뉴·오늘 재편.

## 문제와 시나리오

S01/S06/S09/S23/S24: 현재 가이드는 기존 토큰 MCP와 옛 메뉴 중심이다. 처음 온 지인이 OAuth 연결→점검 저장→재조회까지 스스로 마칠 수 있어야 한다.

## 범위와 계약

- 현재 제품의 기본 연결인 ChatGPT OAuth 안내, 첫 점검 문구, 저장 성공 확인 및 앱에서 다시 보는 흐름을 제공한다. 기존 토큰 연동은 별도 고급 안내로 남긴다.
- ChatGPT UI의 현재 지원/요금제/웹·모바일 제약은 실제 공식 자료와 클라이언트에서 확인한 범위만 안내한다.
- 분석·저장·실제 체결·잔고 확인을 구분한다. 매일 앱/ChatGPT 양쪽 방문, 긴 설문, 과거 거래 복원을 요구하지 않는다.
- 오류/취소/재연결/빈 데이터 안내와 도움말 진입을 통합한다. 새로운 인증 시스템은 만들지 않는다.
- PRD/START-HERE/구현 감사의 배포·검증 상태를 증거에 맞춰 갱신한다. 백업과 배포 성공을 전후 데이터 대조 또는 사용자 격리 완료로 대신하지 않는다.

- [x] 자동 테스트에서 해당 탐색과 오류 처리를 검증하고 실제 Google/ChatGPT 인증 미검증을 구분한다.
- [ ] 본인/지인 계정의 웹·모바일 저장/재조회/격리를 실제 확인한다(필요한 인증은 사용자 수행).
- [x] #39에 5일 출근 사용 관찰 양식: 날짜, 파악 시간, 추가 질문/화면 왕복, 놓친 과제, 재사용 의향을 기록한다.

## 구현 결과와 남은 외부 게이트

- 가이드를 현재 자산 입력 → ChatGPT 개발자 모드에 OAuth MCP 주소 연결 → 첫 점검 문구 전송 → 오늘에서 저장 결과 확인의 네 단계로 재작성했다. 빈 오늘 화면에서도 자산과 연결 가이드로 바로 이동한다.
- 분석·저장·실제 체결·잔고 확인의 의미를 분리하고, 연결 메뉴 없음·승인 취소·오래된 도구 정보·저장 결과 없음·빈 자산의 복구 안내를 한곳에 배치했다. 기존 토큰 MCP는 설정의 고급 연결로 유지한다.
- OpenAI 공식 연결 문서를 앱에서 링크한다. 개발자 모드 가용성은 계정/워크스페이스 정책에 따라 달라질 수 있다고 표시하고, 2026-09-20 소유자 계정에서 관찰한 웹 OAuth·동일 계정 모바일 연결 지속을 모든 사용자 지원 보장과 구분했다.
- 자동 검증은 온보딩 탐색·주소/문구 복사·취소 안내·반응형 화면과 기존 OAuth 승인 UI/인증 회귀를 다룬다. 본인/지인 실제 계정의 새 연결·웹/모바일 저장·재조회·격리 및 5일 파일럿은 사용자 참여가 필요한 외부 게이트로 남는다.
