# [제품 리뷰] OAuth 온보딩과 실제 사용자 흐름 검증

상태: 진행 전 · 2026-09-21
상위: #40. 기존 책임: #33/#36/#39. 선행: 메뉴·오늘 재편.

## 문제와 시나리오

S01/S06/S09/S23/S24: 현재 가이드는 기존 토큰 MCP와 옛 메뉴 중심이다. 처음 온 지인이 OAuth 연결→점검 저장→재조회까지 스스로 마칠 수 있어야 한다.

## 범위와 계약

- 현재 제품의 기본 연결인 ChatGPT OAuth 안내, 첫 점검 문구, 저장 성공 확인 및 앱에서 다시 보는 흐름을 제공한다. 기존 토큰 연동은 별도 고급 안내로 남긴다.
- ChatGPT UI의 현재 지원/요금제/웹·모바일 제약은 실제 공식 자료와 클라이언트에서 확인한 범위만 안내한다.
- 분석·저장·실제 체결·잔고 확인을 구분한다. 매일 앱/ChatGPT 양쪽 방문, 긴 설문, 과거 거래 복원을 요구하지 않는다.
- 오류/취소/재연결/빈 데이터 안내와 도움말 진입을 통합한다. 새로운 인증 시스템은 만들지 않는다.
- PRD/START-HERE/구현 감사의 배포·검증 상태를 증거에 맞춰 갱신한다. 백업과 배포 성공을 전후 데이터 대조 또는 사용자 격리 완료로 대신하지 않는다.

## 인수 조건

- [ ] 새 사용자 안내에서 자산 입력→OAuth→점검 요청→저장→앱 재조회 경로가 연결된다.
- [ ] 자동 테스트에서 해당 탐색과 오류 처리를 검증하고 실제 Google/ChatGPT 인증 미검증을 구분한다.
- [ ] 본인/지인 계정의 웹·모바일 저장/재조회/격리를 실제 확인한다(필요한 인증은 사용자 수행).
- [ ] #39에 5일 출근 사용 관찰 양식: 날짜, 파악 시간, 추가 질문/화면 왕복, 놓친 과제, 재사용 의향을 기록한다.
- [ ] 실제 외부 검증 없이 파일럿이나 인증 성공을 완료 처리하지 않는다.
