# [제품 리뷰] 주요 메뉴 4개와 오늘의 점검 흐름 재편

상태: 완료(로컬 구현) · 2026-09-21
상위: #40. 기존 책임: #34/#36/#43. 선행: 계산 품질 및 판단·할 일 통합.

## 문제와 시나리오

S05~S09/S24: 오늘이 브리핑 목록에 머물러 지금 확인할 일과 변화 파악이 어렵다. 보조 기능이 주 메뉴와 같은 비중이고, 원칙 편집과 현재 배분 계산도 섞여 있다.

## 범위와 계약

- 주 메뉴: 오늘 / 자산 / 판단·할 일 / 투자 원칙. 모바일 하단, PC 좌측. 설정은 보조 진입으로 두고 활동(변경 이력), 도움말, 로그아웃을 연결한다.
- 오늘: 분석일/조사 상태 → 결론 → 변화 최대 3개 → 관련 과제 최대 3개 → 보조 정보. 상세 및 전체 목록으로 이어진다. 중요도/관련성 근거 없이 임의 과제를 오늘 해야 할 일로 단정하지 않는다.
- 당일 이전 분석은 마지막 저장 점검으로 명시하고 no_action을 당시 결론으로 표시한다. 사용자 시간대를 사용한다. 자동 분석이나 강제 매일 점검을 추가하지 않는다.
- 잔고 확인은 보조 정보로 내려 미확인을 오류처럼 강조하지 않는다.
- 자산 네 가지 보기와 표 편집을 보존하고 목표와 비교 진입을 추가한다. 전략 버킷 기준 배분/적립/규칙 계산은 여기에 배치한다.
- 투자 원칙에는 개인 기준·상세 원칙·운용 계획 편집을 둔다. 규칙 계산, 모델 의견, 사용자 결정의 출처를 구분한다.
- 자료는 브리핑/판단 근거에서 연결하며 전체 자료 보관함과 기존 CRUD도 제공한다. 기존 URL/공유 문맥을 유지한다.
- 기존 list/get_daily_briefing, task 조회, strategy/portfolio 읽기를 활용한다. 새 today 테이블이나 자동 생성 모델을 만들지 않는다.

## 구현 결과

- 모바일 하단·PC 좌측에 네 개의 주 메뉴를 두고 자료/활동/설정/가이드/로그아웃을 보조 메뉴로 이동했다. 공유 사용자는 기능 grant가 있는 메뉴만 본다.
- 오늘은 최신 상세를 읽어 분석 시각·조사 범위·당시 결론·중요 변화 3개를 먼저 보여준다. 브리핑에서 판단을 거쳐 명시적으로 연결된 과제만 표시하며, 과제 상세에서 연결 판단으로 이어진다.
- 자산 네 가지 보기를 보존하고 `#allocation` 목표 비교를 추가했다. 목표 비중·적립금·리밸런싱 계산은 이 화면에만, 개인 기준·운용 원칙 편집은 투자 원칙에만 표시한다.
- 기존 hash와 공유 문맥을 유지했다. 단위 59개, 브라우저 E2E 26개, production build와 encoding 검사를 통과했다. 자동 분석·실사용 60초/5일 파일럿·운영 배포는 범위 밖이며 #48/#39에 남긴다.
