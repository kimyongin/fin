# [활동 단순화] 할 일·한 일·판단 결과를 하나의 활동 경험으로 통합

상태: 단순화 반영 · 구현 전 · 2026-09-23
GitHub: https://github.com/kimyongin/fin/issues/81
선행: 01 계약.
기준: [공통 설계](../design/activity-simplification.md), [ADR-0007](../adr/0007-activity-results-and-search.md).

## 목적

U01~U04/U07. 기존 화면을 활용해 활동을 등록·완료·편집하고 후속 할 일을 연결한다.

## 인수 조건

- [ ] 판단 모아보기 탭을 제거하고 할 일→날짜별 한 일로 제공한다. 할 일 완료/한 일 기록 대신 실제 제목과 결과를 표시하며 자동 변경은 변경 내용을 보여준다. 자산 보기와 주 메뉴는 유지한다.
- [ ] 내용만으로 등록하고 결과 없이 빠르게 완료할 수 있다. 완료 시 또는 나중에 같은 활동에 결과를 추가/수정해도 목록은 한 건이다. 메모·태그·판단 상세는 선택으로 제공한다.
- [ ] 수동 제목/날짜/결과를 일반 편집으로 수정한다. 자동 금융 원본은 잠그고 메모/태그만 편집한다. 원본 체결/보유 수정은 기존 금융 기능으로 연결한다.
- [ ] 활동 결과는 같은 activity_events 레코드에 저장하고 별도 결과 레코드/변경 로그를 매번 생성하지 않는다. 수정 시 updated_at 등 필요한 최소 갱신 정보를 유지한다.
- [ ] 후속 할 일 추가는 origin_event_id를 연결하고 양방향 탐색을 제공한다. 결과 메모와 등록된 후속 할 일을 구분하며 기존 출발점을 조용히 덮어쓰지 않는다.
- [ ] 동일 수행의 연결된 결과만 대표 행으로 보여준다. 같은 날짜/제목/세션이나 기존 판단-task 연결만으로 다른 활동을 합치지 않는다.
- [ ] 반복·완료 취소·재개는 기존 기능을 재사용한다. 편집은 편집, 새 활동 추가는 새 기록으로 처리하며 새 판단/설명 정정 자동 분류·강제 대체 흐름을 만들지 않는다.
- [ ] 기존 판단 ID/URL과 오늘·보유 이유·리포트 링크를 보존한다. 실제 DB→OAuth MCP→앱 저장/편집/재조회, 권한·재시도와 관련 화면 폭/상태를 검증한다. #84의 해당 가이드를 동시에 갱신한다.

## 실행 기준

기존 구조를 활용해 필요한 최소 변경을 사용자 기능 단위로 구현한다. 일반 활동에 불변성·별도 결과 저장·의무 수정 이력을 도입하지 않는다. 금융 원본/계산/인증/권한과 기존 재시도·반복 동작은 유지한다. 이번 갱신은 설계·티켓만 변경하며 구현·배포 완료를 뜻하지 않는다.
