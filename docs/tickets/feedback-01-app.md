# [피드백] 햄버거 자유 입력과 본인 접수 내역

우선순위: P1 · 상태: 운영 배포/자동 검증 완료 · 선행: 없음

## 범위

[공통 설계](../design/product-feedback.md)의 F01/F05/F06을 DB→RPC→앱 수직 슬라이스로 구현한다.

- product_feedback, RLS, 제출/본인 목록 RPC, 최소 서버 관리 역할 기반. 관리자 지정은 운영 절차로 수행하며 이메일/UUID를 UI 코드에 고정하지 않는다.
- 햄버거 보조 메뉴 피드백. 자유 텍스트 하나와 등록 버튼, 본인 목록·상태·답변. 기존 AppHeader/constants/탐색 hook 및 공통 화면 컴포넌트 재사용.
- 진입 전 page_key만 선택적 기록. 실패 시 본문/동일 재시도 키 보존, 성공 후 목록 실패는 접수 실패와 구분.
- 공유 포트폴리오 열람 중에도 로그인 사용자 본인에게 귀속. canEdit와 별개인 비익명 인증 기준으로 메뉴 접근 처리.
- schema OVERVIEW 및 관리자 초기 지정/해제·보관/권한 운영 절차 갱신.
