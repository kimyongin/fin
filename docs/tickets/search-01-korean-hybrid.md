# [활동 검색] 한국어 제목·본문 검색 품질과 운영 오류 복구

상태: Pinecone 운영 DB·Edge 적용 및 재색인 완료 · 사용자 요청으로 의미 검색 활성화 · 웹 배포 검증 중 · 실모델 품질 게이트 미달 · 2026-09-28
GitHub: https://github.com/kimyongin/fin/issues/161
기준: [검색 설계](../design/activity-context-search.md). #83의 후속 구현이며 과거 완료 증거를 지우지 않는다.

현재 구현 인계: [Pinecone 임베딩 전환 계약](../design/activity-search-pinecone.md). 2026-09-27 사용자의 교체 요청에 따라 초기 gte-small 유지 선택을 대체한다. 과거 검증·운영 기록은 아래에 보존하며 새 모델의 검증 결과로 사용하지 않는다.

## 목적·소비 시나리오

S1. `투자 이론` 태그에서 `심리`, `불안해서 팔고 싶다`처럼 원문과 다른 표현으로 관련 기록·할 일을 찾는다. 검색 기반은 이 시나리오의 웹·OAuth 결과로 바로 검증한다.

## 구현·완료 조건

- [ ] 운영 `query=심리` 내부 오류의 로그/재현 원인을 확인하고 최소 수정한다. 검색어 없는 정상 조회와 비교하되 런타임 원인을 추측으로 확정하지 않는다.
- [ ] Pinecone 전환 계약의 모델·1024차원·문서/질의 목적·전체 원문 분할·비용·키·재색인·커서 규칙을 구현한다. 실모델 보정 집합과 분리한 최소 24개 검증 질문에서 임계값 이상 top-5 적중 80% 이상 및 무관 질문 6개 의미 결과 0건을 확인한다. 초기 `gte-small` 품질 0/12와 그 당시 품질 게이트 유예는 과거 근거로 보존한다.
- [ ] 기존 검색 RPC와 `_shared/activity-search.ts`를 보완해 할 일 제목/설명·기록 제목/본문을 함께 검색한다. 완료·중단 할 일도 찾고 상태를 구분한다. 도래 실행 큐는 유지한다.
- [ ] 긴 본문 후반부 검색·발췌와 원본별 중복 제거, 태그/종목/기간/권한 선필터, 일관된 페이지 이어보기를 구현한다. 모델/조건 변경 후 커서 재사용은 명확히 거절한다.
- [ ] 저장/수정 후 색인, 백필·실패 재시도·내용 해시와 모델 구분·삭제 즉시 제외를 최소 구조로 구현한다. 기본 저장은 검색 색인 실패와 분리한다.
- [ ] 웹/HTTP·OAuth 동일 계약과 불완전 검색 상태를 표시한다. 기본 탐색 최근 30일/미지정 검색 전체 기간 전환 및 명시적 기간 보존을 적용한다.
- [ ] 실제 모델의 품질, 첫/후속 요청 지연(p50/p95)·검색/색인 비용을 기록한다. 한국어 근거 누락·공유 권한·다른 소유자·오류 fallback·편집 후 재검색을 검증한다.
- [ ] schema OVERVIEW, MCP 설명/가이드/review manifest, 현재 검색 계약을 갱신하고 단위·DB·관련 E2E·Edge·encoding 검사를 통과한다. 운영 배포와 실제 ChatGPT 확인은 별도로 기록한다.

기존 데이터 정본은 보존한다. 검색 파생 색인의 전환·백필·복귀 절차를 준비하고 승인 범위에서 배포한다. 별도 도메인/영구 검색 세션/범용 큐는 선행 도입하지 않는다.

- [ ] Sol에서 실제 프로젝트 플랜·키·모델 접근과 합성 API 호출을 확인한다. CLI 로그인 성공을 서버 키 설정 완료로 간주하지 않는다. 무료 범위 사용이며 유료 전환은 별도 결정이다.
- [ ] 문서 `passage`/질의 `query`, 전체 원문 해시/청크, 12,000자 뒤 근거, 분리된 품질 검증과 임계값 산출을 완료한다. 기존 평가 스크립트의 문서 `query` 호출과 내적 계산도 수정한다.
- [ ] 모델을 식별하는 큐/완료 쓰기, 1024차원 migration, 최신 티커 ranked RPC/coverage/커서, OFF 상태 배포 호환성과 재색인/키워드 복구를 구현·검증한다.
- [ ] HTTP/OAuth·웹·MCP 가이드/manifest·schema OVERVIEW와 실제 품질/지연/토큰 사용량·권한/실패/화면 검증 기록을 갱신한다.
- [ ] 정확한 commit과 대상의 배포안을 준비하고 승인 범위에서 운영 전환한다. 실제 ChatGPT 검증과 소유자 원본 보존 확인을 별도로 남긴다.

### 최종 방식과 구현 범위

- [x] **B: 제목·소제목 문맥을 포함한 문단/문장 단위 원문 임베딩**을 채택했다. 짧은 글은 하나로, 긴 글은 경계를 보존해 분할하며 같은 절의 마지막 짧은 문장을 제한적으로 겹친다.
- [x] 고정 400자 분할은 문맥 손실 때문에 제외했다. 요약 단독은 세부 조건/예외 누락, 요약+본문은 생성·갱신·순위 통합 부담 때문에 이번에는 제외했다. 네 후보 모두 구현하는 비교 실험은 요구하지 않는다. 이는 시나리오/운영 비용에 따른 설계 결정이며 품질 실측 결과가 아니다.
- [x] 분할 함수의 최종 임베딩 입력은 UTF-8 900바이트 이내, 반복 제목/소제목은 각각 120바이트 이내, 동일 절의 마지막 완결 문장 겹침은 120바이트 이하로 정했다. 이는 토큰 수 환산이 아니며 실제 공급자 입력 검증을 통과해야 한다. 세부 경계·짧은 글·긴 제목·코드/표·빈 원문 처리는 전환 계약을 따른다.
- [x] 저장은 기존 벡터 테이블과 큐를 사용한다. DB의 목적별 순수 분할 함수가 청크 번호·원문 발췌·문맥 포함 입력을 반환한다. 별도 요약/청크/상태 테이블을 추가하지 않는다.
- [x] 검색은 제목/단어 일치 우선, 원본별 최고 청크 점수, 원문 발췌, 기존 상세 조회를 사용한다. 요약/본문 점수 합치기나 재정렬 모델은 추가하지 않는다.
- [ ] enqueue·worker 원문 조회·해시·ranked 검색·coverage의 12,000자 제한을 제거한다. 전체 원문 및 `pinecone-e5-context-v1` 식별자로 해시를 계산하고 실제 분할 결과 전체를 처리한다.
- [ ] 현재 모델/해시의 모든 예상 청크 번호에 벡터가 존재해야 완료로 판단한다. 마지막 청크 누락/실패는 pending이다. 제목·소제목·후반부 수정은 원본 전체 재색인을 유발하고 구 작업은 거절한다. 기존 긴 기록도 전환 시 재색인한다.
- [ ] 고정된 검증 질문 최소 24개(주제/세부 조건/부정·예외/다중 주제/문맥 경계/후반부 각각 4개), 무관 질문 6개로 검사한다. Hit@5 전체 최소 20/24, 유형별 최소 3/4, 지정 후반부/예외/경계 사례 전부 통과, 무관 의미 결과 0건을 요구한다. Recall@5·nDCG@5·입력 토큰·벡터 수·비용·지연도 기록한다.
- [ ] 한국어·이모지·긴 URL·구두점 없는 글·숫자/소수점·긴 제목·소제목 전환·코드/표·빈 본문과 허용 최대 입력에서 분할의 결정성, 문자 경계, 겹침 제외 원문 전체 보존, 900바이트 한도와 실제 모델 호출을 검증한다. 12,000자 이후 수정/검색·마지막 청크 실패·중복 원본 제거도 확인한다.

설계와 방식 선정은 완료했다. 확정안 B의 로컬 구현과 자동 검증 결과는 아래에 기록한다. 품질 게이트 실패 후 사용자가 2026-09-28 의미 검색 활성화와 배포를 직접 요청했다. 이 배포 예외는 품질 기준을 충족했다는 뜻이 아니며 실패 사례는 여전히 Astra 설계 검토 대상이다.

### Sol 로컬 구현·검증 · 2026-09-28

- `20260927160000_activity_search_pinecone_context.sql`에서 기존 파생 벡터/대기열을 비우고 `multilingual-e5-large` 1024차원으로 전환했다. 정본 활동/할 일은 보존하며 전체 원문 해시, 문맥 포함 900바이트 청크, 모델을 확인하는 큐/완료 RPC, 최신 티커 ranked 검색과 coverage, 현재 원본 재큐잉을 연결했다. 기존 migration 이력은 수정하지 않았다.
- Edge는 문서 `passage`/질문 `query`를 Pinecone Inference에 보내며 `truncate=NONE`, 응답 차원·모델·유한값을 검사한다. 사용자 자료와 공급자 오류 본문을 로그에 남기지 않는다. 질의 의미 검색은 `ACTIVITY_SEARCH_SEMANTIC_ENABLED=true`에서만 요청한다. 미설정/실패 시 기존 키워드 경로가 동작한다.
- CLI의 현재 프로젝트 관리 키로 합성 한국어 문장 1건을 실제 호출하여 모델명·dense·1024차원·17토큰을 확인했다. 900바이트 이내의 한국어·영문·이모지·URL 합성 입력도 `truncate=NONE`으로 받아들여졌다. 앱 서버용 `PINECONE_API_KEY`는 설정하거나 저장하지 않았고 실제 플랜/잔여량도 확인하지 못했다.
- 30개 합성 문서, 기존 보정 질문 12개/무관 질문 3개, 분리한 검증 질문 24개/무관 질문 6개를 사용했다. 보정 집합에서 정한 코사인 임계값 `0.8059`에서 검증 Hit@5는 **23/24**, 주제·세부·예외·혼합·경계 각 **4/4**, 후반부 **3/4**였다. 후반부의 매도 예외 질문은 기대 문서가 **14위**였고, 무관한 우산 수리 질문은 본문 수정·재색인 합성 문서와 유사도 `0.8084`로 **1/6** 의미 결과에 포함됐다. 후반부 질문은 검색 방법과 매도 예외가 섞여 모호하므로 설계 검토에서 문항 적합성도 판단해야 한다. 문항을 결과에 맞춰 고치지 않았다. 이 평가는 짧은 합성 문서를 직접 `passage`로 임베딩한 것이며 긴 실제 원본의 HTTP 전체 흐름 품질을 입증하지 않는다.
- `npm test`: **131/131**, Deno 전체 Edge 타입 검사, `npm run build`, workflow guide 검사, UTF-8 검사 통과. 최종 전체 본문 해시 수정 후 격리 `.e2e`를 다시 초기화해 DB **783/783**, OAuth MCP/HTTP readiness, 검색 근거 화면 **1/1**을 확인했다. 앞서 활동 화면 브라우저 **25/25**도 통과했다. 검색 근거 화면은 360/390/768/1024/1440px에서 확인했지만 의미 점수 사례는 모의 응답이다. 200% 확대, 실제 ChatGPT, 운영 지연 p50/p95 및 서버 키를 쓴 실제 전체 색인·질의는 미검증이다.
- 인수 기준의 후반부 지정 사례 전부 통과 및 무관 질문 0/6이 충족되지 않았다. 코드·migration은 로컬에 있으며 커밋/푸시/운영 DB·Edge·웹 배포는 하지 않았다. 운영 서비스는 기존 상태다. 다음은 Astra에서 실패 사례와 검색 표현/채택 기준을 검토하는 것이다. 원인과 변경 계약이 확정되기 전에는 운영 전환을 승인안으로 제출하지 않는다.

### 사용자 요청에 따른 운영 전환 · 2026-09-28

- 사용자는 품질 미달과 기본 OFF 상태를 설명받은 뒤 Pinecone 의미 검색의 활성화와 배포를 명시적으로 요청했다. 기존 합성 검증의 후반부 3/4 및 무관 질문 오탐 1/6은 그대로 공개된 한계다. 품질 인수 항목은 미완료로 유지한다.
- 대상은 연결된 Supabase `ubmtflglqudrvumepzij`와 Pinecone 무료 조직의 `Default` 프로젝트다. 무료 플랜은 제한된 `DataPlaneEditor` 키 발급을 거절하여 별도 `ProjectEditor` 키를 발급했고, 합성 입력의 1024차원 호출을 확인한 뒤 Supabase Edge 비밀로만 설정했다. 키 값은 저장소·티켓에 남기지 않았다.
