# agent-02 — Portfolio 장기 사이클 평가 지침

2026-09-30 · Astra 선택을 사용자에게 확인하고 제품 스킬 지침 작성. 로컬 작성·검사와 플러그인 배포·실클라이언트 검증을 구분한다.

## 사용자 시나리오와 범위

사용자는 장기 사이클의 과열·침체를 여러 축으로 평가하고, 필요할 때 결과를 기존 활동에 기록하려 한다. "점검해줘" 대신 대상과 평가·갱신·비교·조회 동작을 구체적으로 표현한다.

- S1: 보유 주식 ETF의 장기 사이클 평가 → 동일 기초 투자 대상을 묶고 근거와 과열도를 대화에 제공.
- S2: 지정 시장 평가·최신 자료 갱신 → 이전 판단과 현재 자료를 비교하고 변화·불확실성을 설명.
- S3: 저장된 최신 평가 조회 → 기존 활동을 읽어 평가일·누락을 표시하고 새 조사 결과로 대체하지 않음.
- S4: 필요한 결과 기록 → 기존 공통 지침과 활동 도구로 처리. 사이클 지침에 별도 저장 규칙을 복제하지 않음.

원본은 [Portfolio SKILL.md](../../plugins/portfolio/skills/portfolio/SKILL.md)와 [cycle-review.md](../../plugins/portfolio/skills/portfolio/references/cycle-review.md)다. 진입 스킬 하나와 참고 문서 일곱 개를 사용한다. 기존 활동·원칙·자산 API로 충분하며 새 DB·점수 저장 API·자산 화면·예약 실행을 추가하지 않는다. 스킬의 갱신 요청은 최신 평가 작성이고 도구에 없는 점수 필드 저장을 뜻하지 않는다.

## 결정

- 가격 부담·투자 열기·가격 과속의 0/25/50/75/100 판단을 동일 가중 평균하고 표시값만 5점 단위 반올림한다. 근거가 부족한 축은 보류하며 종합값도 보류한다.
- 기업 기초체력·경기 및 금융여건·추세 방향은 별도로 설명한다. 경기 악화를 과열 점수에 섞지 않는다.
- 지표·기간·집계 정의와 판단 이유를 보여주는 탐색용 v1이다. 검증된 예측 모델이나 실제 사이클 위치로 안내하지 않는다. 동일 자료가 항상 동일한 정성 판단을 보장하지 않으며 행동 평가에서 재현성을 확인한다.
- PER·CAPE의 중복, 시장 공통 심리와 테마 근거, 동일 ETF의 여러 계좌 보유를 독립 신호로 중복 가산하지 않는다.
- 주식 지수·개별주·테마는 자료 범위를 밝힌다. 채권은 국면·보유 근거를 평가하되 채권용 숫자 척도를 임의로 만들지 않는다.
- 기록 여부·승인·재조회는 공통 스킬과 knowledge-review를 재사용한다. 사용자 개인의 75/45 선호를 모든 사용자에게 강제하지 않는다.

## 검증 기준

형식·링크·도구 참조 검사는 실제 투자 판단 품질이나 웹·모바일 전달을 증명하지 않는다. 배포 후 독립 대화에서 다음을 확인한다.

| 요청/조건 | 기대 행동 |
| --- | --- |
| 보유 S&P500 ETF가 여러 계좌·상품에 존재 | 기초 지수 평가를 공유하고 상품 차이만 설명 |
| 가격 부담 75·열기 50·과속 75 | 평균 66.7을 표시 65로 계산, 건강도·경기를 합산하지 않음 |
| 투자 열기 자료 누락 | 해당 축과 종합값 보류, 결측을 50으로 채우지 않음 |
| 낮은 과열도·기업 실적 훼손 | 단순 매수 권고 대신 충돌과 재검토 조건 설명 |
| 장기채 평가 | PER를 적용하지 않고 금리·물가·듀레이션·환노출 설명, 주식 점수 생성 안 함 |
| 새 ETF·일부 기업만 조사 | 대리 자료와 조사 비중·누락 표시 |
| 저장된 최신 평가 조회 | 저장 내용·평가일을 설명, 새 평가를 만든 것으로 말하지 않음 |
| 갱신 시 이전 평가 없음/방법 변경 | 숫자 변화량을 만들지 않고 비교 불가 표시 |
| 최신 외부 조회 실패 | 변화 없음으로 말하지 않음 |
| 평가와 기록 금지/동의/기존 승인 | 공통 기록 규칙 적용, 승인 범위 밖의 원칙·금융 변경 없음 |

운영 금융 데이터에 검증용 쓰기를 임의로 만들지 않는다. 실제 기록·재조회 검증은 사용자가 요청한 결과나 명시 승인된 시험 자료만 사용한다.
