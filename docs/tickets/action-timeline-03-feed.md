## 목적과 범위
A05. 태스크와 이벤트를 하나의 행동 목록으로 제공하고 완료 행 중복과 번들 선택을 제거한다.

## 인수 조건
- [x] 기본 전체 화면에서 '지금 할 일 → 날짜별 한 일'을 함께 보여준다. 로그가 미완료 과제를 밀어내지 않으며 미래 예정/날짜 없는 과제도 접근 가능하다.
- [x] 날짜별 종류/건수 요약과 접기를 제공한다. 메모/태그 수정 등 작은 변경은 펼치거나 상세에서 모두 확인하며 요약에 LLM 호출은 필요 없다.
- [x] 완료 태스크는 체크/결과, 값 편집은 '수정', 체결은 '매수/매도', 대조는 '확인'으로 구분한다. 모든 이벤트에 완료 체크를 붙이지 않고 아이콘/색 외에 텍스트로 의미를 표시한다.
- [x] 완료 결과를 대표 행으로 표시하고 같은 태스크/회차의 등록·편집은 상세 이력에서 확인한다. 후일 재개/정정과 과거 완료는 보존하고 제목 유사성으로 병합하지 않는다.
- [x] 태스크 없는 이벤트도 이름/대상/시각/결과와 변경 전후 상세가 온전히 보인다. 연결할 태스크를 만들라고 요구하지 않는다.
- [x] 반복 과제는 오늘 회차 우선이며 과거 미실행을 연체 목록에 누적하지 않는다. 과거 회차 이력 접근과 일회성 미완료 과제 노출은 유지한다.
- [x] 행동 이유는 선택 메모/기존 판단 연결로 제공하고 매 편집마다 입력을 요구하거나 추론하지 않는다. 기존 도메인의 필수 정정 사유는 유지한다.
- [x] 혼합 샘플(오늘 과제, 미래/날짜 없는 과제, 메모/태그 수정 다수, 수량 수정, 실제 매수, 태스크 완료/재개, 반복 미실행)로 지금 할 일·최근 변화·결과를 찾을 수 있는지 브라우저 회귀에서 검증했다. 장기 사용성 평가는 운영 배포 뒤 별도 게이트다.
- [x] 전체/할 일/한 일 필터와 날짜 접기
- [x] 완료 이벤트와 task 통합 표시 및 과거 시점 보존
- [x] 필터/권한/중복 제거 후 페이지 경계
- [x] 반복 당일 회차와 독립 자동 이벤트 혼합
- [x] 현재 최근 30건 제한 해소
- [x] 이전 URL·판단 상세·CSV·오늘 연결 유지
- [x] 360/390/768/1024/1440px와 키보드/긴 내용/오류/빈 상태 검증
- [x] 정확한 API signature/오류/권한/날짜 의미와 필요한 최소 모델 계약을 구현 전에 설계 문서에 기록한다.
- [x] 실제 DB→RPC/OAuth→앱 시나리오 검증과 미검증 범위를 기록한다. 문서/가이드 변경 영향과 encoding check를 포함한다.

## 구현 계약과 결과
- `app_list_action_timeline(owner, filter, from, to, limit, cursor, timezone)`가 미완료 task와 성공 event를 한 DTO로 제공한다. `all|pending|done` 필터, `(occurred_at,id)` 커서와 날짜 범위를 서버에서 먼저 적용한다.
- 기본 화면은 미완료 general/research/execution task를 위에 고정하고 수행 이벤트를 `occurrence_on` 우선 날짜로 묶는다. general task 생성/편집 이벤트는 대표 피드에서 숨기고 완료 이벤트 한 건을 대표로 유지한다.
- 공유 조회는 `tasks`와 `activity` 기능 권한을 각각 검사한다. task 권한이 없으면 연결 이벤트도 제외해 개인 과제 제목이나 결과가 활동 권한만으로 노출되지 않는다.
- 앱은 기존 `#tasks`와 `#activity`를 동일한 `활동` 화면으로 연결한다. 전체/할 일/한 일, 날짜별 사실 집계, 접기, 커서 더 보기를 제공하며 독립 이벤트에는 완료 체크를 붙이지 않는다. 추가 진입은 하나로 두고 기본은 할 일로 등록하며, `이미 했음` 옵션을 체크하면 수행일과 결과 메모를 가진 활동으로 기록한다. `매일 반복`과 `이미 했음`은 동시에 선택할 수 없고, 날짜 입력 하나가 일반 할 일에서는 예정일, 반복 할 일에서는 반복 시작일로 동작한다.
- #79 전환까지 반영해 DB 450건, Vitest 102건, Playwright 33건, 빌드/인코딩과 MCP 계약 검사를 통과했다. 운영 배포와 실제 ChatGPT 웹・모바일 평가는 미실행이다.
