# [MCP 가이드] 기능 변경 연동 검사와 시나리오 회귀 평가

우선순위: P1 · 상태: 로컬 구현·자동 검증 완료, 운영/모델 평가 대기 · 2026-09-21
선행: workflow-guide-01-policy · 02와 함께 적용 · 관련 #57/#58

## 목적과 범위

기능만 바뀌고 ChatGPT 안내가 과거 상태로 남는 문제를 예방한다. [공통 설계](../design/contracts/agent/workflow-guide-design.md)의 단일 원본·변경 영향 검사를 개발 및 CI 흐름에 연결한다.

- tool 의존성과 시나리오·소스 경로 매핑을 정적 가이드 원본에 둔다. 문서 참고본은 생성 또는 원본 링크로 유지한다.
- revision은 내용 해시로 식별하며 실제 도구/가이드가 같은 Edge 배포에 포함된다.
- 변경 영향 manifest/check는 관련 tool/schema/handler/RPC 변경에 영향 topic과 갱신 또는 영향 없음 사유를 요구한다. 의미 검토를 사람이 수행함을 명시한다.
- 기존 CI 및 개발/PR 체크리스트에 검사 연결. 매번 전체 가이드 재작성·전용 버전 DB·범용 workflow 엔진은 만들지 않는다.
- #58의 평가 문서에 인터뷰와 복합 작업 사례를 추가하여 기존 평가를 재사용한다.
